# HAND SCULPTOR

手で、ホログラムをつくる。ブラウザで動くAR（インストール不要）。

**▶ https://ikemotodir.github.io/hand-sculptor/**

- カメラの前で手を合わせて、ひらくと3Dが生まれる
- 映像はこの端末の中だけで処理し、ネットには送りません
